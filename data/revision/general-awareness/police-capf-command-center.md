## 1. Police hierarchy

### Institutional command map
| Institution | Level | Typical role |
| :--- | :--- | :--- |
| State police | State-level territorial policing | Law and order, investigation, district administration support |
| Commissionerate police | Metropolitan / urban policing | City policing, urban law and order, crime investigation |
| District police | District-level implementation | Service delivery, investigation, beat policing |
| CAPFs | Central level | Border guarding, internal security, specialized deployment |
| Specialized units (ATS/STF/Cyber) | State / central hybrid | Terror response, organized crime, digital crime investigation |

### Police vs CAPF vs Armed Forces
| Body | Administrative oversight | Core function |
| :--- | :--- | :--- |
| State Police | State governments | Law and order and investigation |
| CAPFs | Central government | Border guarding, internal security deployment |
| Armed Forces | Union government / defence establishment | External defence, war-fighting, strategic operations |

### State police hierarchy
| Rank | Typical level |
| :--- | :--- |
| DGP | Director General of Police |
| ADG | Additional Director General |
| IG | Inspector General |
| DIG | Deputy Inspector General |
| SSP/SP | Senior Superintendent / Superintendent |
| ASP | Additional Superintendent of Police |
| DSP / ACP | Deputy Superintendent / Assistant Commissioner |
| Inspector | Police station leadership |
| SI | Sub-Inspector |
| ASI | Assistant Sub-Inspector |
| Head Constable | Supervisory constabulary |
| Constable | Basic rank |

### Commissionerate system
- Commissioner
- Additional / Joint Commissioner
- Deputy Commissioner of Police
- Assistant Commissioner of Police

### Exam note
Police ranks are not the same as Army ranks. They belong to different service structures.

## 2. CAPFs and main roles

| Force | Full form | Main role | Typical domain |
| :--- | :--- | :--- | :--- |
| BSF | Border Security Force | Border guarding | International border management |
| CRPF | Central Reserve Police Force | Internal security and law and order | Counter-insurgency, anti-Naxal, VIP security |
| CISF | Central Industrial Security Force | Industrial and critical infrastructure security | PSUs, airports, metro, nuclear installations |
| ITBP | Indo-Tibetan Border Police | High-altitude border guarding | India-China border |
| SSB | Sashastra Seema Bal | Border guarding | Nepal, Bhutan border |
| Assam Rifles | Assam Rifles | Border and internal security | Northeast, border deployment |

### Separate security organizations
| Organization | Full form | Main role |
| :--- | :--- | :--- |
| NSG | National Security Guard | Elite anti-terror response |
| SPG | Special Protection Group | VVIP protection |

### Exam fact
CAPFs are central paramilitary forces, not part of the regular armed forces. NSG and SPG are separate specialized security organizations and should not be treated as CAPFs in the same category as BSF, CRPF, CISF, ITBP, SSB or Assam Rifles.

### CAPF command perspective
| Force | Primary role | Typical operational domain |
| :--- | :--- | :--- |
| BSF | Border guarding | International land borders |
| CRPF | Internal security and law and order | Counter-insurgency, riots, VIP security |
| CISF | Security of vital infrastructure | Airports, ports, PSU installations |
| ITBP | High-altitude and frontier security | China frontier / mountain terrain |
| SSB | Border management and security | Nepal-Bhutan frontier |
| Assam Rifles | Border and internal security | Northeast and border support |
| NSG | High-risk anti-terror and tactical intervention | Strike / counter-terror response |

## 3. Special police units

### ATS
- Anti-Terrorism Squad
- Specialized in terror-related investigations and intelligence coordination

### STF
- Special Task Force
- Specialized in organized crime, intelligence-driven operations, and serious crime investigations

### Special Branch
- Political and intelligence support to police administration
- Important in broader security coordination

### Cyber Crime Police / Cyber Cells
- Digital fraud, hacking, cybercrime, digital evidence and digital investigation

### Crime Branch / EOW
- Economic offences, financial crime, organized fraud, and serious financial investigation

### Key distinction
- ATS focuses on terror-related work.
- STF focuses on specialized crime and intelligence-driven operations.
- Special Branch works in broader intelligence and administrative support roles.

### Specialized unit comparison
| Unit | Main domain | Common exam cue |
| :--- | :--- | :--- |
| ATS | Terror investigation and terror-related coordination | Terror strikes, interrogation, intelligence linkages |
| STF | Organized crime, serious crime, targeted operations | Serious criminal networks and intelligence-driven action |
| Special Branch | Administrative and political-intelligence support | Internal security coordination |
| Cyber Crime Cell | Digital fraud, cyber offences, forensic digital investigation | Hacking, cyber scams, online fraud |
| EOW / Crime Branch | Financial crime and economic offences | Money laundering, fraud, organized financial crime |

## 4. Internal security architecture

India’s internal security structure includes:
- State police
- Central Armed Police Forces
- NIA, IB, NSG, CAPFs
- State intelligence and anti-terror units
- Cybersecurity units and digital investigation mechanisms

### Major internal security challenges
- Terrorism and radicalization
- Left-wing extremism
- Illegal trafficking and narcotics
- Cybercrime and digital fraud
- Border infiltration and cross-border security issues
- Critical infrastructure protection

## 5. UP Police and special units

### UP Police framework
- State police structure includes district police, commissionerates, STF, ATS, PAC, and specialized units.
- Territorial policing and intelligence coordination are key to law and order.

### UP STF
- Special Task Force
- Focuses on serious crime, organized crime, and specialized security investigations

### UP ATS
- Anti-Terrorism Squad
- Works on terror-related investigations and inter-agency coordination

### PAC
- Provincial Armed Constabulary
- State-level armed force for law and order support and critical security operations

### UPSSF
- UP Special Security Force / state security-structured support function by public administrative context
- Must be treated as a state-specific specialized security arrangement, not a central armed force

## 7. Quick revision one-liners

- Police and military are separate service structures.
- CAPFs are not part of the Army, Navy, or Air Force.
- ATS and STF are different agencies with different operational focus.
- NSG is a specialized counter-terror force, not a military regiment.
- IB and RAW differ by broad domain: internal vs external intelligence.
- State police are the first-line law-and-order force.
- CAPFs are central formations, while police are mostly state-level institutions.
