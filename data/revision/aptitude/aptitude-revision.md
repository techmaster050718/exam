## 1. Percentage

### Core Percentage Formulas

**Formula(s):**
```
Percentage = (Part / Whole) × 100

Part = (Percentage × Whole) / 100

% Change = [(New Value - Old Value) / Old Value] × 100
         = [(Change) / Original] × 100

x% of y = y% of x  (Interchange property)
```

**Variables:**
- `Part` = the portion of the whole being considered
- `Whole` = the total/base value
- `% Change` = percentage increase (+) or decrease (−)

**Example:**
> In an exam, Rahul scored 360 marks out of 500. What is his percentage?
> Percentage = (360/500) × 100 = **72%**

> A price increases from ₹200 to ₹250. % increase = (50/200) × 100 = **25%**

**Shortcut:**
- To find x% of a number N: Move decimal → multiply. E.g., 15% of 240 = 10%(24) + 5%(12) = **36**
- Successive % changes: Net effect of a% then b% = `a + b + (ab/100)`
  - E.g., +20% then −20% = 20 + (−20) + (20×−20/100) = **−4%** (net loss)
- If A is x% more than B, then B is `[x/(100+x)] × 100`% less than A

**⚠️ Common Trap:**
- "20% increase then 20% decrease ≠ 0%" — always use the net formula
- Base changes in multi-step percentage problems — always identify what the NEW base is
- "What % of A is B?" ≠ "What % of B is A?" — read carefully!

## 2. Profit & Loss

### Core Profit & Loss Formulas

**Formula(s):**
```
Profit (P)       = Selling Price (SP) − Cost Price (CP)
Loss (L)         = Cost Price (CP) − Selling Price (SP)
Profit%          = (Profit / CP) × 100
Loss%            = (Loss / CP) × 100

SP = CP × (100 + P%) / 100   [when profit]
SP = CP × (100 − L%) / 100   [when loss]
CP = SP × 100 / (100 + P%)   [when profit]
CP = SP × 100 / (100 − L%)   [when loss]

Marked Price (MP) related:
SP = MP × (100 − Discount%) / 100
```

**Variables:**
- `CP` = Cost Price (amount paid to acquire)
- `SP` = Selling Price (amount received on sale)
- `MP` = Marked / Listed Price
- `P%` = Profit percentage (always on CP)
- `L%` = Loss percentage (always on CP)

**Example:**
> An item bought for ₹800 is sold at ₹960. Find profit%.
> Profit = 960 − 800 = ₹160; Profit% = (160/800) × 100 = **20%**

> SP = ₹650 at 20% loss. Find CP.
> CP = 650 × 100/(100−20) = 650 × 100/80 = **₹812.50**

**Shortcut:**
- If a person sells two items at same SP, one at x% profit and other at x% loss:
  **Net result is always LOSS** = (x²/100)%
- Profit% when CP and SP given: `(SP−CP)/CP × 100`
- If CP of n items = SP of m items → Profit% = `(n−m)/m × 100`

**⚠️ Common Trap:**
- Profit% and Loss% are ALWAYS calculated on **CP**, not SP — exam questions try to confuse this
- "10% profit on SP" ≠ "10% profit on CP"
- Dishonest dealer using false weights: Profit% = `(True Weight − False Weight)/False Weight × 100`

---

### Profit & Loss — Key Relationships

```
     CP ──────────────→ SP
           × (100±%)
                 ÷100

If SP > CP → PROFIT
If SP < CP → LOSS
If SP = CP → No profit, No loss
```

| Condition | Formula |
|-----------|---------|
| Find SP from CP with P% | SP = CP(100+P%)/100 |
| Find SP from CP with L% | SP = CP(100−L%)/100 |
| Find CP from SP with P% | CP = SP×100/(100+P%) |
| Find CP from SP with L% | CP = SP×100/(100−L%) |

## 3. Discount

### Core Discount Formulas

**Formula(s):**
```
Discount       = Marked Price (MP) − Selling Price (SP)
Discount%      = (Discount / MP) × 100
SP             = MP × (100 − d%) / 100

Successive Discounts d1% and d2%:
Net Single Discount = d1 + d2 − (d1 × d2)/100

Profit% after discount (if CP known):
Profit% = [(SP − CP)/CP] × 100
```

**Variables:**
- `MP` = Marked Price / List Price / MRP
- `SP` = Selling Price (after discount)
- `d%` = Discount percentage (always on MP)
- `CP` = Cost Price of the article

**Example:**
> MP = ₹1200, Discount = 15%. Find SP.
> SP = 1200 × (100−15)/100 = 1200 × 85/100 = **₹1020**

> Successive discounts of 20% and 10%:
> Net discount = 20 + 10 − (20×10)/100 = 30 − 2 = **28%**

**Shortcut:**
- Two successive discounts a% and b%: Equivalent = (a + b − ab/100)%
- If profit% and discount% are given, find CP:
  CP = MP × (100−d%)/(100+P%)
- Always: Discount% is on MP; Profit% is on CP

**⚠️ Common Trap:**
- Discount is calculated on **Marked Price**, NOT on Cost Price
- 20% discount + 20% profit does NOT mean profit equals discount — CP and MP are different bases
- Successive discounts of 25% and 25% ≠ 50% discount

> 📦 **MUST REMEMBER — Discount vs Profit**
> - Discount on MP | Profit on CP — two different bases!
> - Successive discount formula: a + b − ab/100

## 4. Simple Interest

### Core Simple Interest Formulas

**Formula(s):**
```
SI  = (P × R × T) / 100

A   = P + SI = P(1 + RT/100)

P   = (SI × 100) / (R × T)
R   = (SI × 100) / (P × T)
T   = (SI × 100) / (P × R)
```

**Variables:**
- `P` = Principal (initial amount)
- `R` = Rate of interest per annum (%)
- `T` = Time in years
- `SI` = Simple Interest
- `A` = Amount (Principal + Interest)

**Example:**
> P = ₹5000, R = 8% p.a., T = 3 years
> SI = (5000 × 8 × 3)/100 = **₹1200**
> Amount = 5000 + 1200 = **₹6200**

**Shortcut:**
- If SI for T years at R% = same amount as SI for different terms → set up proportion
- Rule of 72: Number of years to double money at R% ≈ 72/R (approximate)
- When T is in months: T = months/12; when days: T = days/365

**⚠️ Common Trap:**
- Ensure T is in YEARS; if given in months, divide by 12
- "Interest doubled" means SI = P, not A = 2P... wait, A = 2P means SI = P ✓
- When rate changes each year — add each year's interest separately

## 5. Compound Interest

### Core Compound Interest Formulas

**Formula(s):**
```
A  = P × (1 + R/100)ⁿ          [annual compounding]
CI = A − P

Half-yearly:   A = P × (1 + R/200)²ⁿ
Quarterly:     A = P × (1 + R/400)⁴ⁿ

Effective CI for 2 years:
CI = P × R/100 × (2 + R/100)
   = 2PR/100 + PR²/10000

Difference CI − SI for 2 years:
CI − SI = P × (R/100)²

Difference CI − SI for 3 years:
CI − SI = P(R/100)² × (3 + R/100)

Growth formula: A = P(1 + r/100)ⁿ
Depreciation:   A = P(1 − r/100)ⁿ
```

**Variables:**
- `P` = Principal
- `R` = Rate % per annum
- `n` = Number of years (time periods)
- `A` = Final Amount
- `CI` = Compound Interest

**Example:**
> P = ₹10,000, R = 10% p.a., T = 2 years (CI)
> A = 10000 × (1.1)² = 10000 × 1.21 = **₹12,100**
> CI = ₹2100 | SI = ₹2000 | Difference = **₹100** = P×(R/100)² = 10000×(0.1)²=100 ✓

**Shortcut:**
- For 2 years: CI = SI + (SI × R)/(2 × 100)  where SI is for 2 years
- For 3 years: CI − SI = P(R/100)² (R/100 + 3)
- Use (1.05)² = 1.1025; (1.1)² = 1.21; (1.1)³ = 1.331 — memorize these!

**⚠️ Common Trap:**
- Half-yearly → rate becomes R/2, time becomes 2n — both change!
- CI is always GREATER than SI for same P, R, T (when T > 1)
- Depreciation uses (1 − r/100)ⁿ, not (1 + r/100)ⁿ

> 🃏 **30-SECOND REVISION CARD — Interest**
> ```
> SI  = PRT/100          (linear growth)
> CI  = P(1+R/100)ⁿ − P (exponential growth)
> CI > SI always (for T>1)
> CI−SI (2yr) = P(R/100)²
> Half-yearly: rate÷2, time×2
> ```

## 6. Ratio & Proportion

### Core Ratio & Proportion Formulas

**Formula(s):**
```
Ratio a:b = a/b

Proportion: a:b = c:d  ⟺  a×d = b×c  (cross-multiply)

Componendo: (a+b)/(a−b) = (c+d)/(c−d)

Dividendo: (a−b)/b = (c−d)/d

Componendo & Dividendo: (a+b)/(a−b) = (c+d)/(c−d)

If a:b = c:d, then b is mean proportional if a:b = b:c
   → b² = ac  → b = √(ac)

Third proportional to a, b: x such that a:b = b:x → x = b²/a

Fourth proportional to a,b,c: x such that a:b = c:x → x = bc/a
```

**Variables:**
- `a, b, c, d` = quantities in ratio/proportion
- Antecedent = first term of ratio; Consequent = second term

**Example:**
> Ratio of A:B = 3:5. If B = 40, find A.
> A = (3/5) × 40 = **24**

> Mean proportional between 4 and 25:
> x = √(4 × 25) = √100 = **10**

**Shortcut:**
- If ratio is a:b, total parts = a+b; A's share = a/(a+b) × Total
- To compare ratios: cross-multiply. 3/4 vs 4/5 → 15 vs 16 → 4/5 > 3/4
- If a:b = x:y and b:c = p:q → a:b:c = xp:yp:yq

**⚠️ Common Trap:**
- Ratio a:b ≠ b:a; order matters
- When quantities are increased/decreased — add/subtract from both sides then find ratio
- "Ratio of ages NOW" vs "ratio of ages X years ago" — read the time reference!

## 7. Partnership

### Core Partnership Formulas

**Formula(s):**
```
Simple Partnership (same time):
Profit share ∝ Capital invested
A:B = CA:CB

Compound Partnership (different time):
Profit share ∝ Capital × Time
A:B = (CA × TA):(CB × TB)

If sleeping partner and working partner:
Working partner gets salary first, then profit split
```

**Variables:**
- `CA, CB` = Capital invested by A and B
- `TA, TB` = Time period of investment
- Profit split ratio = Equivalent Capital ratio

**Example:**
> A invests ₹6000 for 6 months, B invests ₹8000 for 9 months. Split profit of ₹4700.
> A's equivalent = 6000×6 = 36000; B's = 8000×9 = 72000
> Ratio = 36000:72000 = 1:2
> A's share = (1/3)×4700 = **₹1566.67**; B's = **₹3133.33**

**Shortcut:**
- Always compute Capital × Time as a product, then simplify ratio
- Sleeping partner = only money; working partner = money + labor (salary from profit first)

**⚠️ Common Trap:**
- Simple partnership = same time → only capital ratio matters
- Compound partnership = different times → must use Capital × Time
- Withdrawal mid-way: Split into two periods for that partner

> 📦 **MUST REMEMBER — Partnership**
> Partnership ratio = Capital × Time for each partner
> Working partner extracts salary before profit split

## 8. Average & Ages

### Core Average Formulas

**Formula(s):**
```
Average = Sum of all items / Number of items
Sum     = Average × Number of items

Weighted Average:
Avg = (w₁x₁ + w₂x₂ + ... + wₙxₙ) / (w₁ + w₂ + ... + wₙ)

If a new member joins with value x:
New Avg = (Old Sum + x) / (Old n + 1)

If a member leaves with value x:
New Avg = (Old Sum − x) / (Old n − 1)

Average of first n natural numbers   = (n+1)/2
Average of first n even numbers      = n+1
Average of first n odd numbers       = n
Average of consecutive numbers       = (First + Last)/2
```

**Variables:**
- `n` = count of items
- `wᵢ` = weight of item i
- `xᵢ` = value of item i

**Example:**
> Average of 5 numbers is 20. A 6th number 50 is added. New average?
> Old sum = 5×20 = 100; New sum = 100+50 = 150; New avg = 150/6 = **25**

**Shortcut:**
- Change in average when x is added: New avg = Old avg + (x − Old avg)/(n+1)
- If avg increases by d after adding x: x = Old avg + d×(n+1)
- Replacement trick: If member of value x replaced by y: Change in avg = (y−x)/n

**Ages Shortcuts:**
```
Present age problems: Let current age = x, set up equation from given conditions
"n years ago" → subtract n; "n years hence" → add n
Sum of ages now = Sum of ages n years ago + (n × number of people)
```

**⚠️ Common Trap:**
- "Average age increased by 2" after replacement ≠ new person is 2 years older; use formula
- Avg of consecutive odd/even numbers = middle term (for odd count)
- Don't forget: average speed ≠ (speed1 + speed2)/2 when distances are equal

## 9. Mixture & Allegation

### Core Mixture & Allegation Formulas

**Formula(s):**
```
Alligation Rule:
Cheaper (C) ───────────── Dearer (D)
                 Mean (M)
      (D−M)              (C−M)

Ratio of mixing Cheaper:Dearer = (D−M):(M−C)

Mixture formula:
If a vessel contains x litres of liquid A and y litres replaced n times:
Remaining A = x × (1 − y/x)ⁿ

For two mixtures mixed:
Resultant concentration = (c₁V₁ + c₂V₂)/(V₁ + V₂)
```

**Variables:**
- `C` = Price/concentration of cheaper ingredient
- `D` = Price/concentration of dearer ingredient
- `M` = Mean price/desired concentration
- `x` = total volume; `y` = volume replaced; `n` = number of replacements

**Example:**
> Mix rice at ₹15/kg with rice at ₹20/kg to get mixture at ₹17/kg. Find ratio.
> Cheaper=15, Dearer=20, Mean=17
> Ratio = (20−17):(17−15) = 3:2 (Cheaper:Dearer)

> A 40L mixture has milk:water = 3:1. 10L removed and 10L water added. New ratio?
> Milk remaining = 30 × (3/4) = 30×(1 − 10/40) = 30×(3/4) → Initially milk=30L
> After removing 10L (mix ratio 3:1): milk removed=7.5L, water removed=2.5L
> New milk=22.5, water=10+7.5+10=... use formula: Milk=30×(1−10/40)=30×0.75=22.5L, Water=17.5L → Ratio=22.5:17.5= **9:7**

**Shortcut:**
- Cross-diagram (alligation) is the fastest method for mixture ratios
- Replacement formula: Final = Initial × ((Total−Replaced)/Total)^n

**⚠️ Common Trap:**
- In alligation, the cross goes from dearer to cheaper quantity, not concentration difference in same direction
- When mixing three items: use pairwise alligation and combine
- C must be < M < D for the alligation to be valid

> 🃏 **30-SECOND REVISION CARD — Mixtures**
> ```
> Alligation Ratio = (D−M):(M−C)
> Draw X diagram: C on left, D on right, M in middle
> Cross subtract: (D−M) goes to C side, (M−C) goes to D side
> Replacement: Remaining = x(1−y/x)ⁿ
> ```

## 10. Time & Work

### Core Time & Work Formulas

**Formula(s):**
```
If A can do a work in n days:
A's 1 day work = 1/n

If A and B together finish in T days:
1/T = 1/A + 1/B  →  T = AB/(A+B)

For 3 persons A, B, C:
1/T = 1/A + 1/B + 1/C

Work done = Efficiency × Time
If efficiency ratio = a:b, time ratio = b:a (inverse)

MDH formula:
M₁D₁H₁/W₁ = M₂D₂H₂/W₂
(M=men, D=days, H=hours/day, W=work)
```

**Variables:**
- `A, B, C` = number of days each person takes alone
- `T` = combined time
- `M, D, H, W` = Men, Days, Hours, Work

**Example:**
> A does work in 12 days, B in 15 days. How long together?
> T = (12×15)/(12+15) = 180/27 = **6.67 days**

> A and B together: 10 days. A alone: 15 days. B alone?
> 1/B = 1/10 − 1/15 = (3−2)/30 = 1/30 → B = **30 days**

**Shortcut:**
- Use LCM method: LCM of their individual days = Total work units
  A=12 days, B=15 days → LCM=60; A does 5u/day, B does 4u/day; Together=9u/day; Time=60/9=6.67 days
- If A is x times as efficient as B → A takes 1/x the time B takes
- Work completed by A alone after B leaves = find work left and divide by A's rate

**⚠️ Common Trap:**
- "A is twice as fast as B" → A takes HALF the time, not double
- Work is about RATES (1/day), not days directly — add rates, not days!
- "Together they can finish in 6 days" — 1/A + 1/B = 1/6, not A+B=6

## 11. Pipes & Cisterns

### Core Pipes & Cisterns Formulas

**Formula(s):**
```
Inlet pipe fills in A hours → rate = +1/A
Outlet pipe empties in B hours → rate = −1/B

Net rate = 1/A − 1/B
Time to fill = AB/(B−A)  [when B > A, i.e., inlet faster]

If multiple inlets and outlets:
Net rate = Σ(inlet rates) − Σ(outlet rates)
Time = 1/Net rate
```

**Variables:**
- `A` = time for inlet pipe to fill tank alone
- `B` = time for outlet pipe to empty tank alone
- Net rate is positive if filling, negative if emptying

**Example:**
> Pipe A fills in 6h, Pipe B empties in 12h. Both open — time to fill?
> Net rate = 1/6 − 1/12 = 2/12 − 1/12 = 1/12
> Time = **12 hours**

> Pipe A fills in 10h, B fills in 15h, C empties in 30h. All open — time?
> Net rate = 1/10 + 1/15 − 1/30 = 3/30 + 2/30 − 1/30 = 4/30 = 2/15
> Time = **7.5 hours**

**Shortcut:**
- Same LCM trick as Time & Work — assign LCM as capacity, compute rates per hour
- If a leak is introduced: New time = 1/(fill rate − leak rate)
- "Tank fills in T hours if no leak; leak makes it T' hours" → Leak rate = 1/T' − 1/T... wait: 1/T − leak = 1/T' → leak = 1/T − 1/T' → empties alone in TT'/(T'−T)

**⚠️ Common Trap:**
- Outlet pipe SUBTRACTS from net rate — sign is negative!
- Tank already half-full: remaining work = 1/2, not full work
- If both inlet and outlet are opened simultaneously when tank is partially full — account for initial level

> 📦 **MUST REMEMBER — Pipes & Cisterns**
> Inlet = positive rate (+1/A)
> Outlet = negative rate (−1/B)
> Net time = 1 / (net rate)

## 12. Time, Speed & Distance

### Core Speed-Distance-Time Formulas

**Formula(s):**
```
Speed = Distance / Time
Distance = Speed × Time
Time = Distance / Speed

Unit conversions:
x km/h = x × 5/18 m/s
x m/s  = x × 18/5 km/h

Average Speed:
If equal distances at speeds u and v:
Average Speed = 2uv/(u+v)  [Harmonic Mean]

If equal times at speeds u and v:
Average Speed = (u+v)/2    [Arithmetic Mean]

Relative Speed:
Same direction:   |u−v|
Opposite dir.:    u+v
```

**Variables:**
- `u, v` = speeds of two objects
- `D` = distance; `T` = time; `S` = speed

**Example:**
> A travels 60km at 30km/h, then 60km at 60km/h. Average speed?
> Avg = 2×30×60/(30+60) = 3600/90 = **40 km/h** (NOT 45!)

> Convert 72 km/h to m/s: 72 × 5/18 = **20 m/s**

**Shortcut:**
- Always use 2uv/(u+v) for equal distance (not arithmetic mean)
- For 3 equal segments at speeds a, b, c: Avg = 3abc/(ab+bc+ca)
- Time gained/saved: If speed increased by factor k, time = original/k

**⚠️ Common Trap:**
- Average speed ≠ average of speeds unless time is equal (not distance)
- "A is 20 mins late" → convert to hours before computing
- Relative speed in same direction = difference; opposite = sum

## 13. Boats & Streams

### Core Boats & Streams Formulas

**Formula(s):**
```
Let: b = speed of boat in still water
     s = speed of stream/current

Downstream speed (D/S) = b + s
Upstream speed (U/S)   = b − s

From above:
b = (Downstream + Upstream) / 2
s = (Downstream − Upstream) / 2

Time downstream = Distance / (b+s)
Time upstream   = Distance / (b−s)
```

**Variables:**
- `b` = boat speed in still water
- `s` = stream speed
- Downstream = with current (faster)
- Upstream = against current (slower)

**Example:**
> Boat speed = 10 km/h, stream = 2 km/h. Time to go 24km downstream and return?
> D/S = 12 km/h, U/S = 8 km/h
> Time downstream = 24/12 = 2h; Time upstream = 24/8 = 3h
> Total time = **5 hours**

**Shortcut:**
- If D/S and U/S given: boat speed = (D/S + U/S)/2; stream = (D/S − U/S)/2
- If man can row x km downstream and y km upstream in same time:
  Distance ratio = (b+s):(b−s)

**⚠️ Common Trap:**
- "Downstream is faster" — yes, add stream speed
- Do NOT confuse boat speed in still water with boat speed in stream
- If stream speed = boat speed → upstream speed = 0 (stationary upstream)

## 14. Trains

### Core Train Formulas

**Formula(s):**
```
Time for train to pass a stationary pole/person:
T = Length of train / Speed of train

Time for train to pass a platform/bridge:
T = (Length of train + Length of platform) / Speed of train

Two trains same direction:
T = (L₁ + L₂) / (S₁ − S₂)   [relative speed = difference]

Two trains opposite direction:
T = (L₁ + L₂) / (S₁ + S₂)   [relative speed = sum]

Speed = Distance / Time (convert units as needed)
```

**Variables:**
- `L₁, L₂` = lengths of trains
- `S₁, S₂` = speeds of trains
- For a person (stationary): distance = train length only
- For a bridge/platform: distance = train length + bridge length

**Example:**
> Train 150m long at 60km/h passes a platform 100m long. Time?
> Speed = 60 × 5/18 = 50/3 m/s
> Distance = 150 + 100 = 250m
> Time = 250 ÷ (50/3) = 250 × 3/50 = **15 seconds**

**Shortcut:**
- Always convert km/h → m/s (multiply by 5/18) when length in metres
- For crossing a person: use only train length
- Same direction: trains "cross" when total length is covered at relative speed

**⚠️ Common Trap:**
- "Train passes a man sitting in another train" → use relative speed and sum of lengths
- Platform length added to train length, NOT subtracted
- When two trains start simultaneously from opposite ends: use combined speed

> 🃏 **30-SECOND REVISION CARD — Motion**
> ```
> S = D/T always
> km/h → m/s: × 5/18 | m/s → km/h: × 18/5
> Avg speed (equal dist): 2uv/(u+v)
> Train + pole: only train length
> Train + platform: train length + platform length
> Boats: b=(DS+US)/2, s=(DS−US)/2
> ```

## 15. Number System

### HCF and LCM

**Formula(s):**
```
HCF × LCM = Product of two numbers  (for 2 numbers only!)
HCF(a,b) divides both a and b exactly

HCF by Euclidean: HCF(a,b) = HCF(b, a mod b) until remainder = 0

LCM = (a × b) / HCF(a,b)   [for two numbers]

For fractions:
HCF of fractions = HCF(Numerators) / LCM(Denominators)
LCM of fractions = LCM(Numerators) / HCF(Denominators)
```

**Example:**
> HCF(48, 72): 72 = 1×48 + 24; 48 = 2×24 + 0 → HCF = **24**
> LCM(48,72) = 48×72/24 = **144**

---

### Divisibility Rules

| Divisor | Rule |
|---------|------|
| 2       | Last digit even (0,2,4,6,8) |
| 3       | Sum of digits divisible by 3 |
| 4       | Last 2 digits divisible by 4 |
| 5       | Last digit 0 or 5 |
| 6       | Divisible by both 2 and 3 |
| 7       | (2×last digit subtracted from rest) divisible by 7 |
| 8       | Last 3 digits divisible by 8 |
| 9       | Sum of digits divisible by 9 |
| 10      | Last digit 0 |
| 11      | Alternating sum (odd positions − even positions) divisible by 11 |
| 12      | Divisible by both 3 and 4 |
| 13      | (4×last digit added to rest) divisible by 13 |

---

### Remainder Theorems

**Formula(s):**
```
Remainder Theorem: f(a) mod m
Fermat's Little Theorem: aᵖ⁻¹ ≡ 1 (mod p) where p is prime, gcd(a,p)=1

Cyclicity of remainders:
2¹=2, 2²=4, 2³=8, 2⁴=16 → unit digits: 2,4,8,6 (cycle of 4)
3¹=3, 3²=9, 3³=27, 3⁴=81 → unit digits: 3,9,7,1 (cycle of 4)
7¹=7, 7²=49, 7³=343, 7⁴=2401 → unit digits: 7,9,3,1 (cycle of 4)
9¹=9, 9²=81 → unit digits: 9,1 (cycle of 2)

Wilson's Theorem: (p−1)! ≡ −1 (mod p) for prime p
```

**Shortcut:**
- Unit digit of aⁿ: find cyclicity, compute n mod (cyclicity length), use that power's unit digit
- Remainder when divided by 9: equals sum of digits mod 9 (digit sum)
- Remainder when divided by 11: alternating sum mod 11

**⚠️ Common Trap:**
- HCF × LCM = Product applies ONLY to two numbers, not three or more
- For LCM of fractions: LCM(numerators)/HCF(denominators)
- Divisibility by 11: alternating sum can be negative — that's fine, check if divisible by 11

### Number Types Quick Reference

| Type | Definition | Example |
|------|-----------|---------|
| Natural | 1,2,3... | 1 to ∞ |
| Whole | 0,1,2,3... | 0 to ∞ |
| Integer | ...,−2,−1,0,1,2,... | All |
| Prime | Divisible by 1 and itself | 2,3,5,7,11... |
| Co-prime | HCF=1 | (8,15) |
| Perfect | Sum of proper divisors = itself | 6,28,496 |

**Prime Shortcut:** Check divisibility up to √n; if none divide n, it's prime.
- 2 is the ONLY even prime
- 1 is NEITHER prime NOR composite

> 📦 **MUST REMEMBER — Number System**
> HCF×LCM = a×b (2 numbers only!)
> HCF(fractions) = HCF(num)/LCM(den)
> LCM(fractions) = LCM(num)/HCF(den)
> 1 is neither prime nor composite
> 2 is the only even prime

## 16. Simplification & Approximation

### BODMAS Rule

**Formula(s):**
```
BODMAS Order:
B = Brackets: (), {}, []  — innermost first
O = Orders (powers, roots)
D = Division
M = Multiplication
A = Addition
S = Subtraction

Approximation: Round values to nearest convenient number, solve, verify answer is closest option
```

**Key Identities for Simplification:**
```
a² − b² = (a+b)(a−b)
(a+b)² = a² + 2ab + b²
(a−b)² = a² − 2ab + b²
(a+b)³ = a³ + 3a²b + 3ab² + b³
(a−b)³ = a³ − 3a²b + 3ab² − b³

Sum formulas:
1 + 2 + ... + n = n(n+1)/2
1² + 2² + ... + n² = n(n+1)(2n+1)/6
1³ + 2³ + ... + n³ = [n(n+1)/2]²
```

**Shortcut:**
- Approximation: Round to nearest 10/100, solve, then pick closest answer
- Use (a+b)(a−b) to avoid squaring: 99×101 = (100−1)(100+1) = 10000−1 = **9999**
- 999×1001 = 999001 (use same identity)

**⚠️ Common Trap:**
- BODMAS: Division before Multiplication is WRONG — left to right for D and M
- Similarly, Addition before Subtraction is order-dependent — left to right
- √(a²+b²) ≠ a+b

## 17. Surds & Indices

### Core Surds & Indices Formulas

**Formula(s):**
```
Laws of Indices:
aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿbⁿ
(a/b)ⁿ = aⁿ/bⁿ
a⁰ = 1  (a ≠ 0)
a⁻ⁿ = 1/aⁿ
a^(1/n) = ⁿ√a
a^(m/n) = ⁿ√(aᵐ)

Surds — Rationalizing:
1/(a+√b) = (a−√b)/[(a+√b)(a−√b)] = (a−√b)/(a²−b)

√a × √b = √(ab)
√a / √b = √(a/b)
```

**Variables:**
- Surd = irrational root (√2, ³√5, etc.)
- Index/Exponent = power to which base is raised

**Example:**
> Simplify: 2³ × 2⁴ / 2⁵ = 2^(3+4−5) = 2² = **4**

> Rationalize: 1/(3+√2) = (3−√2)/(9−2) = (3−√2)/7

> (√3 + √2)(√3 − √2) = 3 − 2 = **1**

**Shortcut:**
- If aˣ = aʸ → x = y (same base → equate exponents)
- If aˣ = bˣ → a = b (same exponent → equate bases)
- 0.001 = 10⁻³; 0.0001 = 10⁻⁴ — useful for approximation

**⚠️ Common Trap:**
- (a+b)² ≠ a² + b²; it equals a² + 2ab + b²
- √(a+b) ≠ √a + √b (classic trap!)
- a⁰ = 1 for all non-zero a; 0⁰ is undefined

## 18. Linear & Quadratic Equations

### Linear Equations

**Formula(s):**
```
Linear: ax + b = 0 → x = −b/a

Two variables: ax + by = c and px + qy = r
Solutions by: Substitution, Elimination, Cross-multiplication

Cross-multiplication for ax+by=c, px+qy=r:
x = (br−cq)/(aq−bp)
y = (cp−ar)/(aq−bp)
```

### Quadratic Equations

**Formula(s):**
```
ax² + bx + c = 0

Roots: x = [−b ± √(b²−4ac)] / 2a

Discriminant D = b² − 4ac:
D > 0 → 2 real distinct roots
D = 0 → 2 equal real roots
D < 0 → no real roots (complex)

Sum of roots α+β = −b/a
Product of roots αβ = c/a

Forming equation from roots: x² − (α+β)x + αβ = 0
```

**Example:**
> x² − 5x + 6 = 0 → (x−2)(x−3) = 0 → x = **2 or 3**
> Sum = 5 = 5/1 ✓; Product = 6 = 6/1 ✓

> Solve: 2x + 3y = 11 and 3x + 2y = 9
> Multiply first by 3, second by 2: 6x+9y=33 and 6x+4y=18
> Subtract: 5y = 15 → y = 3 → x = (11−9)/2 = 1

**Shortcut:**
- Factorize: find two numbers that multiply to ac and add to b
- Nature of roots: check D without solving
- For equal roots: b² = 4ac → find unknown

**⚠️ Common Trap:**
- ax² + bx + c: a is coefficient of x² (not a constant!)
- Sum of roots = −b/a (negative sign — often forgotten)
- Both roots can be negative — don't assume roots are positive

## 19. Algebraic Identities

### Essential Identities

**Formula(s):**
```
(a+b)²     = a² + 2ab + b²
(a−b)²     = a² − 2ab + b²
(a+b)(a−b) = a² − b²
(a+b)³     = a³ + 3a²b + 3ab² + b³
(a−b)³     = a³ − 3a²b + 3ab² − b³
a³ + b³    = (a+b)(a² − ab + b²)
a³ − b³    = (a−b)(a² + ab + b²)
(a+b+c)²   = a² + b² + c² + 2(ab+bc+ca)
a³+b³+c³−3abc = (a+b+c)(a²+b²+c²−ab−bc−ca)
If a+b+c=0 → a³+b³+c³ = 3abc
```

**Example:**
> Find a²+b² if a+b=10 and ab=24:
> (a+b)² = a²+2ab+b² → 100 = a²+b²+48 → a²+b² = **52**

> a³+b³+c³ if a+b+c=0: = **3abc**

**Shortcut:**
- If a+b = S and ab = P: a²+b² = S²−2P; a³+b³ = S³−3SP
- Use (a+b)(a−b) = a²−b² for quick calculation: 998² = (1000−2)² = 1000000−4000+4 = **996004**

**⚠️ Common Trap:**
- (a+b)² ≠ a²+b² — the 2ab term is frequently missed
- a³+b³+c³ = 3abc ONLY when a+b+c = 0

> 📦 **MUST REMEMBER — Algebra**
> (a+b)² = a²+2ab+b²; (a−b)² = a²−2ab+b²
> a²−b² = (a+b)(a−b)
> a³±b³ = (a±b)(a²∓ab+b²)
> a+b+c=0 ⟹ a³+b³+c³=3abc

## 20. Mensuration

### 2D Shapes

**Formula(s):**
```
TRIANGLE:
Area = (1/2) × base × height
Area = √[s(s−a)(s−b)(s−c)]  [Heron's formula, s=(a+b+c)/2]
Area (equilateral, side a) = (√3/4)a²
Perimeter = a + b + c

RECTANGLE:
Area = l × b
Perimeter = 2(l+b)
Diagonal = √(l²+b²)

SQUARE (side a):
Area = a²; Perimeter = 4a; Diagonal = a√2

CIRCLE (radius r):
Area = πr²; Circumference = 2πr
Sector area = (θ/360)×πr²; Arc length = (θ/360)×2πr

TRAPEZIUM:
Area = (1/2)(a+b)×h  [a,b = parallel sides, h = height]

PARALLELOGRAM:
Area = base × height = ab×sinθ

RHOMBUS:
Area = (1/2)×d₁×d₂  [d₁,d₂ = diagonals]
Side = √[(d₁/2)² + (d₂/2)²]
```

### 3D Shapes

**Formula(s):**
```
CUBE (side a):
Volume = a³
Surface Area (TSA) = 6a²
Lateral Surface Area = 4a²
Diagonal = a√3

CUBOID (l×b×h):
Volume = l×b×h
TSA = 2(lb + bh + hl)
Diagonal = √(l²+b²+h²)

CYLINDER (radius r, height h):
Volume = πr²h
TSA = 2πr(r+h)
CSA = 2πrh

CONE (radius r, height h, slant l):
l = √(r²+h²)
Volume = (1/3)πr²h
TSA = πr(r+l)
CSA = πrl

SPHERE (radius r):
Volume = (4/3)πr³
Surface Area = 4πr²

HEMISPHERE (radius r):
Volume = (2/3)πr³
TSA = 3πr²
CSA = 2πr²
```

**Example:**
> Cylinder: r=7cm, h=10cm. Volume = π×49×10 = 490π = **1540 cm³** (π≈22/7)
> CSA = 2×(22/7)×7×10 = **440 cm²**

**Shortcut:**
- Use π = 22/7 for most calculations; π = 3.14 for approximations
- Equilateral triangle: Area = (√3/4)a² ≈ 0.433a²
- For any cylinder/cone/sphere change: volume scales as cube of radius ratio

**⚠️ Common Trap:**
- TSA includes base(s); CSA/LSA does NOT include base
- Cone slant height l = √(r²+h²), not l = h
- Diameter vs radius — read the question!
- When a solid is melted and recast: **volume stays the same**

> 🃏 **30-SECOND REVISION CARD — Mensuration**
> ```
> Circle: Area=πr², C=2πr
> Sphere: V=(4/3)πr³, SA=4πr²
> Cylinder: V=πr²h, CSA=2πrh
> Cone: V=(1/3)πr²h, l=√(r²+h²)
> Cube: V=a³, TSA=6a², d=a√3
> Equilateral △: Area=(√3/4)a²
> Melting/Recasting: volumes equal!
> ```

## 21. Probability

### Core Probability Formulas

**Formula(s):**
```
Probability P(E) = Favourable outcomes / Total outcomes

0 ≤ P(E) ≤ 1
P(E) + P(E') = 1  [E' = complement of E]

Addition Rule:
P(A∪B) = P(A) + P(B) − P(A∩B)

For mutually exclusive events:
P(A∪B) = P(A) + P(B)  [P(A∩B)=0]

Multiplication Rule:
P(A∩B) = P(A) × P(B|A)

For independent events:
P(A∩B) = P(A) × P(B)

Conditional Probability:
P(A|B) = P(A∩B) / P(B)
```

**Variables:**
- `E` = event; `S` = sample space
- `A∩B` = both A and B occur
- `A∪B` = A or B (or both) occur

**Standard Sample Spaces:**
```
Coin (1): {H, T}  → 2 outcomes
Coin (2): {HH,HT,TH,TT} → 4 outcomes
Die (1): {1,2,3,4,5,6} → 6 outcomes
Die (2): 36 outcomes
Deck of cards: 52 cards
  → 4 suits × 13 cards
  → 4 aces, 4 kings, 4 queens, 4 jacks
  → 26 red (hearts+diamonds), 26 black (clubs+spades)
```

**Example:**
> P(getting sum=7 when two dice thrown)?
> Favourable: (1,6),(2,5),(3,4),(4,3),(5,2),(6,1) = 6 outcomes
> P = 6/36 = **1/6**

**Shortcut:**
- P(at least one) = 1 − P(none)
- P(exactly k out of n) = ⁿCₖ × pᵏ × (1−p)^(n−k) [Binomial]

**⚠️ Common Trap:**
- "Or" means union (A∪B), use addition rule; "And" means intersection (A∩B)
- With replacement: events are independent; without replacement: they are not!
- P(A) can be 0 or 1 — not just between exclusive extremes

## 22. Permutation & Combination

### Core P&C Formulas

**Formula(s):**
```
Factorial: n! = n × (n−1) × (n−2) × ... × 1; 0! = 1

Permutation (arrangement — order matters):
ⁿPᵣ = n! / (n−r)!

Combination (selection — order doesn't matter):
ⁿCᵣ = n! / [r! × (n−r)!]

ⁿCᵣ = ⁿCₙ₋ᵣ   [symmetry]
ⁿC₀ = ⁿCₙ = 1
ⁿC₁ = n

Relationship: ⁿPᵣ = ⁿCᵣ × r!

Circular Permutation:
Arrangements of n items in a circle = (n−1)!
If clockwise and anti-clockwise are same = (n−1)!/2

Identical items:
Arrangements of n items with p identical, q identical... = n!/(p!×q!×...)
```

**Variables:**
- `n` = total items
- `r` = items chosen/arranged
- P = permutation (order matters)
- C = combination (order doesn't matter)

**Example:**
> In how many ways can 4 books be arranged on a shelf?
> ⁴P₄ = 4! = **24 ways**

> From 6 students, select a committee of 3:
> ⁶C₃ = 6!/(3!×3!) = 720/(6×6) = **20 ways**

> Arrange MISSISSIPPI (11 letters, M=1,I=4,S=4,P=2):
> = 11!/(1!×4!×4!×2!) = **34650**

**Shortcut:**
- ⁿCᵣ quick: build Pascal's triangle row; use ⁿCᵣ = ⁿCₙ₋ᵣ to pick smaller r
- Keyword guide: "arrange/order/seat" → Permutation; "select/choose/committee" → Combination
- For "at least one": ⁿC₁+ⁿC₂+...+ⁿCₙ = 2ⁿ − 1

**⚠️ Common Trap:**
- Circular arrangement: (n−1)! not n!
- Identical objects: divide by factorial of count of each identical group
- "At least 2" = Total − (none + exactly 1) — faster than adding all valid cases

> 📦 **MUST REMEMBER — P&C**
> Order matters → Permutation (ⁿPᵣ)
> Order doesn't matter → Combination (ⁿCᵣ)
> ⁿPᵣ = ⁿCᵣ × r!
> Circle: (n−1)!
> Identical items: n!/[p!q!...]

## 23. Data Interpretation Strategy

### How to Approach DI Sets

**Step-by-Step Strategy:**
```
1. SCAN (10 seconds): Read the graph title, axes, units, legend
2. UNDERSTAND type: Bar / Line / Pie / Table / Mixed
3. NOTE the base year/reference if comparative data
4. READ the questions BEFORE deep-reading data
5. ESTIMATE where possible — eliminate wrong options
6. CALCULATE only what's needed for each question
```

### Common DI Calculations

**Formula(s):**
```
% share of X in total = (X / Total) × 100

% change from year A to year B = [(B−A)/A] × 100

Ratio comparison: cross-multiply instead of dividing

Average = Sum / Count

Growth rate = (Current − Previous) / Previous × 100
CAGR = [(Final/Initial)^(1/n) − 1] × 100
```

**Shortcuts for DI:**
- For % comparisons: eliminate obviously wrong options first
- For large numbers: work in thousands/lakhs/crores consistently
- Pie chart: each 1% = 3.6°; a sector = (value/total)×360°
- Bar charts: read from axis carefully — check if Y-axis starts at 0
- For ratio: if A/B vs C/D — cross multiply to avoid division

**Common DI Question Types:**

| Question Type | Approach |
|---------------|----------|
| Find % increase | (New−Old)/Old × 100 |
| Find ratio | Directly read and simplify |
| Find average | Sum all values, divide by count |
| Find total | Add all given parts |
| Find % of total | Part/Total × 100 |
| Compare two values | Approximate and eliminate |
| Find rank | Sort and count |

**⚠️ Common Trap:**
- "Increase by 50%" vs "increased TO 150" — very different!
- Pie chart angles: total should be 360°; check given data sums to 100%
- Table DI: row total vs column total — read question carefully
- "In which year is the increase maximum?" → find absolute increase, not % increase
- Y-axis may not start at 0 on bar charts — causing perceived differences to be exaggerated

> 🃏 **30-SECOND REVISION CARD — DI Strategy**
> ```
> SCAN → UNDERSTAND → NOTE BASE → READ QUESTIONS → ESTIMATE → CALCULATE
> % change = (New−Old)/Old × 100
> Pie sector angle = (Part/Total) × 360°
> Always check units (lakhs vs crores)
> Eliminate wrong options before calculating
> ```
